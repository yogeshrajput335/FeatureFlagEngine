# FeatureFlagEngine
Feature flags (also known as feature toggles) are commonly used in modern applications to control functionality at runtime without requiring code changes or redeployments. Instead of hard-coding whether a feature is enabled, applications evaluate a feature flag to decide which behaviour to execute.
